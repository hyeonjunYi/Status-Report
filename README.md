# 동향보고·경조사알림 전용 사이트

## 최초 게시
1. 기존 Emergency_Report와 별개로 Trend_Report라는 GitHub 저장소를 만듭니다.
2. 이 폴더 **안의 파일**을 저장소 최상위에 업로드합니다. 폴더째 올리지 않습니다.
3. 저장소 Settings → Pages에서 Deploy from a branch, main, /(root)를 선택해 저장합니다.
4. 배포 주소의 /editor.html에 접속합니다.
5. 연동설정에 새 저장소(예: hyeonjunyi/Trend_Report), main, 새 저장소 Contents 읽기·쓰기 권한이 있는 토큰을 입력합니다.
6. 서식 선택 → 내용 입력 → 미리보기 → GitHub 즉시배포 순으로 진행합니다.

이전 화재보고의 연동정보를 자동으로 가져오지 않습니다. 기존 토큰이 새 저장소 접근 권한을 갖고 있다면 그대로 입력할 수 있습니다. 토큰은 코드에 적지 않고 연동설정에서 입력합니다.

## 서식 및 저장
- 소방차량 사고: 사고 개요, 인명·차량·기타 피해, 사진, 시간대별 상황, 향후계획.
- 직원 부상: 사고 개요, 부상현황, 조치사항, 사진, 시간대별 상황, 향후계획.
- 경조사알림: 제공한 부고 서식 기준. 보고 기준시각은 입력·출력·백업에서 제외합니다.
- 시간대별 상황: 한 줄마다 `09:00 | 상황 내용` 형식으로 작성합니다.
- 마음 전하실 곳: 은행/계좌번호/예금주가 모두 비어 있으면 표시하지 않습니다.
- 지도는 입력한 주소로 외부 지도에서 조회합니다.
- JSON 백업/불러오기, 사진 첨부, HTML 저장, 인쇄/PDF를 지원합니다.
- 사진은 새로고침 시 복구되지 않으므로 사진까지 보관하려면 JSON 백업을 저장합니다.
- GitHub 게시 시 index.html을 교체합니다. 이전 보고서는 HTML/JSON으로 별도 보관합니다.
- 초기 index.html은 안내 화면입니다. 이미 보고서를 게시한 후에는 초기 index.html을 재업로드하지 않습니다.

## 이번 수정
서식은 드롭다운에서 선택합니다. 새 보고서의 보고 기준시각·발생일시·경조사 일시·발인은 한국 현재 시각으로 채워집니다. 경조사만 요일을 표시합니다. 시간대별 상황도 현재 시각으로 첫 줄을 준비합니다. 수동 수정한 일시는 미리보기·저장·게시 시 변경하지 않습니다. 경조사에는 보고 기준시각이 없습니다. 센터장/책임자 항목은 삭제했습니다.
기존 사이트 업데이트 시 editor.html, editor.js, editor.css, report.js 네 파일을 교체하고 index.html은 유지합니다.

## 경조사 공통 서식 확장
경조사 선택 후 부고/결혼/회갑/돌잔치/기타를 선택합니다. 발인과 장지는 부고에서만 입력·출력합니다. 나머지는 예식일시 또는 행사일시와 행사장을 사용합니다. 추가 안내에 주차·교통·참석 관련 내용을 입력할 수 있습니다. 계좌정보는 선택 사항이며 보고 기준시각은 표시하지 않습니다. 기존 백업은 제목에 결혼/회갑/돌잔치가 있으면 해당 유형으로 불러오며, 나머지는 부고로 열립니다. 필요하면 종류를 바꿔 주세요. 이미 게시한 보고서에는 작성페이지에서 올바른 종류를 선택 후 다시 게시해야 적용됩니다.
